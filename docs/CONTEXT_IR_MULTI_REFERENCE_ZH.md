# Context-IR 多参考图解析

本功能只增强 Context-IR 的“输入解析与编译前语义层”。它不会跳过人工审核，也不会替换现有的视频生成、成片审核或合成成片流程。

## 保持不变的制作流程

导航和业务顺序保持原样：

1. 脚本与分镜
2. 成片审核
3. 合成成片

既有 H3 工作流、Fast / Quality 档位、采样步数、LoRA、SeedVR2、审核批准版本、转场选择和最终 MP4 合成都不由本功能修改。

## 新的解析行为

每张被选为 Context-IR 图片参考的素材都会在编译前获得独立记录：

- `image_id`、原始来源路径、SHA256、宽高和用途；
- 已声明的 `product_id` 或 `subject_id`（没有就保持未知）；
- 逐图预检、OCR/视觉卡片分析和缓存键；
- 从前端选择、后端上传、原生编译到语义质量门的 `trace_id` 记录。

图片不会因为位置排在第三张或之后被截断。相同商品的多角度图只会在同时满足“已声明为同一商品”及“逐图视觉验证通过”时合并为一个商品主体；不同商品、人物和不确定关系始终保持独立。图片所在文件夹和数组位置都不是身份依据。

## 容量与失败处理

- Context-IR 原生工作流继续自行校验实际媒体槽位；当前服务的图片上限仍是 9 张、参考视频上限仍是 3 段。
- 若某张图片损坏、哈希变化、无法读取或模型分析输出无效，任务会停在编译前并写入带图片 ID、SHA256、阶段和错误类型的追踪记录；不会静默退化为纯文本生成。
- 直接输入 H3 的图片数量受工作流约束。未能直连的额外参考不会被伪称为等强度视觉条件；其独立语义证据仍保留在编译记录中。

## 兼容性

单图、双图、纯文本及历史冻结任务可以继续读取；单图和双图仍调用原有的本地 Context-IR 图片解析器。三张及以上图片才进入新增的逐图分析与融合适配器。新建多图任务使用 `context-references-v1` 记录；旧快照没有该记录时仍按旧路径读取，不会被强制重写。
